# 🍽️ Zomato Clone

A front-end clone of the Zomato homepage built using **HTML** and **CSS**. This project replicates the design and layout of the original Zomato landing page.

## 🌐 Live Demo

👉 [View Live Site](https://aswanthnarayan.github.io/ZomatoClone/)

## ✨ Features

- Zomato-style layout and design
- Responsive homepage with header, banner, and popular locations
- Styled using only HTML and CSS
- Clean and semantic code structure

## 🛠 Tech Stack

- HTML5
- CSS3
